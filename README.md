# Снежное Дом — интерактивный прототип

Статический deployable-прототип для демонстрации инвесторам.

## Что работает

- Главная с hero, поиском, фильтрами и карточками объектов.
- Отдельные каталоги продажи и аренды, сортировка, фильтры и режим карты.
- Индивидуальные страницы объектов с собственными данными и галереями.
- Избранное с сохранением в браузере.
- Демонстрационные сценарии: запись на просмотр, сообщения, телефон и профиль.
- Трёхшаговое размещение объявления с экраном подтверждения.
- Отдельное направление инвестиционных объектов с примерами «до / после».
- Адаптивная верстка для мобильного экрана.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер из этой папки.

## Деплой на Vercel

Импортируйте папку проекта в Vercel как обычный static project. Build command не нужен, output directory — корень проекта.

Это демонстрационный прототип: данные и заявки хранятся только в браузере и не уходят на сервер.
